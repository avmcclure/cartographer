# Cartographer

Agent-first documentation framework: crawls an organisation's repositories and maps its dependencies and data flows. See `README.md`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `avmcclure/cartographer` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
